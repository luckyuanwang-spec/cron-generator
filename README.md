# Cron Expression Generator

Free online cron expression generator and parser. Build cron schedules visually, validate expressions, and see next execution times.

**Live Demo**: https://cron-generator-kappa.vercel.app

## Features

- **Visual Cron Builder**: Select options through dropdown menus to build cron expressions
- **Quick Presets**: One-click presets for common schedules
- **Next Run Calculator**: See the next 10 execution times
- **Cron Parser**: Parse and validate existing cron expressions
- **Human-Readable Descriptions**: Understand what your cron expression means
- **Bilingual Support**: English and Chinese (中文)

## Tech Stack

- Pure HTML/CSS/JavaScript (no dependencies)
- Hosted on Vercel
- SEO optimized with meta tags

## Deployment

2. Connect to Vercel
